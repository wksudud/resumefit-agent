# Sample Job Description — AI Agent Application Engineer
# Synthetic JD for demo purposes. Targets AI Agent / LLM Application Engineering.

## Position
**AI Agent Application Engineer** (Junior / Intern)

## Company Context
A technology company building LLM-powered internal tools and customer-facing AI products.

## Responsibilities
- Design and implement multi-agent workflows for domain-specific problem solving.
- Build and maintain LLM-powered applications using prompt engineering, RAG, and tool-use patterns.
- Develop evaluation frameworks and evidence-based quality metrics for AI agent outputs.
- Collaborate with domain experts to translate business requirements into agent specifications.
- Write clean, tested, documented Python code for internal tools and demos.
- Package AI agent projects with clear README, evidence traces, and reproducible demos.

## Required Skills
- Proficiency in Python and familiarity with common data science libraries (pandas, numpy).
- Understanding of LLM APIs (OpenAI-compatible) and prompt engineering fundamentals.
- Experience with at least one AI application project (course project, personal project, or internship).
- Basic knowledge of agent architecture patterns (planning, tool use, multi-agent orchestration).
- Ability to write structured technical documentation and project READMEs.

## Preferred Skills
- Experience with Streamlit or similar rapid prototyping frameworks.
- Familiarity with RAG (retrieval-augmented generation) architectures.
- Understanding of evaluation metrics for LLM outputs (accuracy, faithfulness, relevance).
- Experience with version control (Git) and project structure conventions.
- Domain knowledge in a specific vertical (e.g., telecom, healthcare, finance) plus AI application experience.

## Seniority
Junior / Intern level. Looking for demonstrated project experience and learning ability over years of experience.

## Red Flags for This Role
- Candidates who only list ML model training without application engineering signals.
- Over-reliance on API calls without workflow design or evaluation thinking.
- No evidence of structured project documentation or reproducible work.
