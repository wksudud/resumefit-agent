# 中文示例岗位描述 — AI Agent 应用工程师
# 示例 JD 为合成内容，面向 AI Agent / LLM 应用工程方向。

## Position
**AI Agent 应用工程师**（初级 / 实习）

## Company Context
一家技术公司，正在建设 LLM 驱动的内部工具和面向客户的 AI 产品。

## Responsibilities
- 设计并实现面向具体业务场景的多 Agent 工作流。
- 使用 prompt engineering、RAG 和 tool-use 模式构建并维护 LLM 应用。
- 设计评估框架和基于证据的质量指标，用于衡量 AI Agent 输出质量。
- 与领域专家协作，将业务需求转化为 Agent 规格说明。
- 编写清晰、可测试、有文档的 Python 代码，用于内部工具和演示项目。
- 将 AI Agent 项目打包为可复现 demo，包括 README、证据追踪和运行说明。

## Required Skills
- 熟练使用 Python，并了解常见数据科学库（pandas、numpy）。
- 理解 LLM API（OpenAI-compatible）和 prompt engineering 基础。
- 至少完成过一个 AI 应用项目（课程项目、个人项目或实习项目均可）。
- 了解 Agent 架构模式，包括 planning、tool use、多 Agent 编排。
- 能够编写结构化技术文档和项目 README。

## Preferred Skills
- 有 Streamlit 或类似快速原型框架经验。
- 熟悉 RAG（检索增强生成）架构。
- 理解 LLM 输出评估指标，例如准确性、忠实度、相关性。
- 熟悉 Git 版本控制和项目结构规范。
- 具备某一垂直领域知识，例如通信、医疗、金融，并能结合 AI 应用落地。

## Seniority
初级 / 实习岗位。更看重可展示的项目经验和学习能力，而不是工作年限。

## Red Flags for This Role
- 只罗列机器学习模型训练经历，缺少应用工程信号。
- 过度依赖 API 调用，但缺少工作流设计和评估思维。
- 没有结构化项目文档或可复现作品。
